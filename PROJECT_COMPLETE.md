### 📚 **Асинхронная библиотека**

#### Основной пакет (`ghoul_quiz/`)
- `client.py` (181 строк) - Low-level HTTP клиент
  - SSL context для self-signed сертификатов
  - Правильное управление токенами (X-Temporary-Token vs Bearer)
  - Встроенная обработка ошибок

- `session.py` (328+ строк) - High-level API wrapper
  - 5 методов API (токен, регистрация, верификация, вопрос, ответ)
  - `register_interactive()` для удобной регистрации
  - Методы загрузки/сохранения токенов
  - Context managers поддержка

- `register.py` (520+ строк) - Token Manager
  - Автоматическое определение режима (dev/prod)
  - Конфигурируемое хранилище токенов
  - Поддержка env переменной `GHOUL_QUIZ_TOKEN_PATH`
  - JSON-based персистентность

- `models.py` - Data модели с type hints
- `types.py` - Type подсказки
- `__init__.py` - Экспорты

#### Обработка ошибок
- ✅ `ValidationError` - некорректные данные
- ✅ `UnauthorizedError` - проблемы с токеном
- ✅ `NotFoundError` - ресурс не найден
- ✅ `RateLimitError` - превышен лимит
- ✅ `APIError` - общие ошибки API
