# 🎮 Викторина на базе Ghoul Quiz API

Два полноценных приложения для интерактивной игры в викторину из Tokyo Ghoul!

## 📚 Файлы

### 1. `quiz_game.py` - Классическая викторина

Базовая версия с полной функциональностью:

```bash
python examples/quiz_game.py
```

**Режимы:**
- 🎯 **Интерактивный**: Играйте сколько угодно вопросов
- ⚡ **Автоматический**: 5 вопросов подряд

**Функции:**
- ✅ Вход по email с сохранением сессии
- ✅ Система подсчета баллов
- ✅ Сохранение статистики в JSON
- ✅ История всех вопросов и ответов
- ✅ Процент точности в реальном времени
- ✅ Рейтинговая система

**Пример использования:**
```python
from examples.quiz_game import QuizGame
import asyncio

async def main():
    game = QuizGame()  # по умолчанию https://chestor.site/api
    await game.play(auto_mode=False)
    await game.close()

asyncio.run(main())
```

### 2. `quiz_game_advanced.py` - Расширенная викторина

Профессиональная версия с множеством режимов:

```bash
python examples/quiz_game_advanced.py
```

**Режимы игры:**

#### 1️⃣ На время (Time Attack) ⏱️
- Ответьте на максимум вопросов за 60 секунд
- Бонусные очки за скорость
- Идеально для соревнований

```
⏱️  РЕЖИМ НА ВРЕМЯ: 60 секунд!
Осталось: 58 сек
❓ Что означает слово "гуль"?
Ответ: _
```

#### 2️⃣ Выживание (Survival) ❤️
- Начните с 3 жизнями
- Теряйте жизнь за каждую ошибку
- Как долго вы сможете продержаться?

```
❤️  РЕЖИМ ВЫЖИВАНИЯ: 3 жизней!
❤️  Жизни: ❤️ ❤️ ❤️
📊 Правильно: 5/7
❓ Вопрос...
```

#### 3️⃣ Челлендж (Challenge) 🚀
- Система мультипликатора (1.0x - 5.0x+)
- Каждый правильный ответ увеличивает мультипликатор
- Одна ошибка сбрасывает мультипликатор на 1.0x
- Финальный счет = базовые очки × максимальный мультипликатор

```
🚀 РЕЖИМ ЧЕЛЛЕНДЖ: Растущая сложность!
🎯 Мультипликатор: 1.0x
🔥 Серия: 0
❓ Вопрос...
```

#### 4️⃣ Таблица рекордов 🏆
- Автоматическое сохранение результатов
- Топ-100 рекордов
- Сортировка по очкам

```
🏆 ТАБЛИЦА РЕКОРДОВ
Место  Игрок          Очки      Режим       Точность
🥇    Chestor         8500      challenge   95.2%
🥈    Player2         7200      time_attack 85.0%
🥉    Player3         6800      survival    72.5%
```

**Функции:**
- 🎖️ Система достижений (в разработке)
- 📊 Подробная статистика
- 💾 Сохранение рекордов
- 🔄 Различные режимы сложности
- ⚡ Реал-тайм счет

## 🎮 Система очков

### Классическая игра
- По 100 очков за каждый правильный ответ

### Режим на время
- По 100 очков за правильный ответ
- Бонус за скорость: (3600 - секунды_прошедшие) / 10
- Пример: 5 ответов за 30 сек = 500 + (3600-30)/10 = 857 очков

### Режим выживания
- По 100 очков за правильный ответ
- Бонус за сохраненные жизни: жизни × 500

### Режим челленджа
- (Правильные ответы × 100) × максимальный мультипликатор
- Мультипликатор = 1.0 + (правильные_подряд × 0.1)
- Пример: 10 правильных подряд = 1000 × 2.0 = 2000 очков

## 🔐 Вход

Обе игры просят email. Если для него есть сохранённая сессия, игра начинается сразу:

```
Введите email: user@example.com
✅ Сессия user@example.com загружена
```

Иначе на почту придёт 6-значный код:

```
Введите email: newuser@example.com
📧 Sending a login code to newuser@example.com...
✅ Код отправлен, проверьте свою почту и закончите регистрацию.
🔐 Enter the 6-digit code from the email: 123456
✅ Logged in!
💾 Session saved for newuser@example.com
```

Гостевой режим в играх не поддерживается: гостям сервер не отдаёт правильные ответы.

Если сессия закончилась (не заходили больше 30 дней или вышли на всех устройствах), игра сообщит об этом. В следующий раз войдите заново.

## 🐛 Решение проблем

### Проблема: "ModuleNotFoundError: No module named 'ghoul_quiz'"
**Решение:**
```bash
cd /home/chestor/ghoul_quiz_lib
pip install -e .
```

### Проблема: "ConnectionError" при подключении к API
**Решение:**
- Проверьте, что API отвечает: `curl https://chestor.site/api/health`
- Проверьте интернет соединение
- Используйте правильный базовый URL

### Проблема: "SSL: CERTIFICATE_VERIFY_FAILED"
**Решение:**
- У `https://chestor.site` валидный сертификат, проверка SSL включена
- Обновите системные сертификаты (пакет `ca-certificates`) или `certifi`
- Для локального сервера с самоподписанным сертификатом: `GhoulQuizAPI(base_url=..., verify_ssl=False)`
