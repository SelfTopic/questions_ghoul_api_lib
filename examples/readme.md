# 📚 Примеры Ghoul Quiz

Перед запуском установите библиотеку из корня репозитория: `pip install -e .`

| Файл | Что показывает |
|---|---|
| [quickstart.py](quickstart.py) | Минимум: вход (сохранённая сессия или код из письма), вопрос, ответ |
| [demo.py](demo.py) | Статус сервера, гостевой доступ и его ограничения, затем вход пользователя |
| [quiz_game.py](quiz_game.py) | Классическая викторина: интерактивный и автоматический режимы, статистика в JSON |
| [quiz_game_advanced.py](quiz_game_advanced.py) | Режимы «на время», «выживание», «челлендж» и таблица рекордов |

```bash
python examples/quickstart.py
python examples/demo.py
python examples/quiz_game.py
python examples/quiz_game_advanced.py
```

Для игр нужен вход по email: гостям сервер не отдаёт правильные ответы, и проверить ответ было бы нечем. После первого входа сессия сохраняется и обновляется автоматически, так что код из письма больше не понадобится, пока вы заходите хотя бы раз в 30 дней.

Управлять сохранёнными сессиями (просмотр, выход, выход на всех устройствах) удобно утилитой `ghoul-quiz-register`.
